🚀 Getting Started
Option 1: Just open it (easiest)

Download index.html
Open it in your browser
Enter your Anthropic API key when prompted
Start journaling!

Option 2: GitHub Pages (share with the world)

Fork this repository
Go to Settings → Pages
Set source to main branch
Your app is live at https://yourusername.github.io/ai-mood-journal

🔑 Getting an API Key

Go to console.anthropic.com
Sign up for a free account
Create an API key
Paste it into the app

🛠️ How It Works
You type how you feel
        ↓
Claude AI reads your entry
        ↓
AI detects your mood + intensity
        ↓
You get personalized advice & affirmations
        ↓
Entry saved to your journal history
